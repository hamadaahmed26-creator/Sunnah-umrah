# OpenDua recordings for human review

Recitation by Muhammad Jumah for OpenDua. Ihsan Labs at the Human Development Fund publishes these recordings as part of its edition of *Hisn al-Muslim* by Saʿīd ibn ʿAlī ibn Wahf al-Qaḥṭānī. The six MP3 files are unmodified copies from audio release v0.0.2. The publisher credits Muhammad Jumah, transliterated as “Muhammad Juma” in the original MP3 artist metadata. Open index.html to listen locally. Each track has its original publisher URL, publisher Arabic, reviewer notes, SHA-256 and length in candidates.json. The four individual selections, Talbiyah, the phrase between the corners, the hilltop remembrance and the two-word takbir, have matching word sequences in the publisher's catalogue. The takbir comes from a different chapter and supplies pronunciation only. The Safa recording combines two consecutive cards. The mosque-entry recording contains a longer invocation. No version-pinned match for the Miqat phrase was identified. [Catalogue v0.0.4](https://opendua.org/v0.0.4/catalogue.json)

A full FFmpeg decode succeeded for all six originals. No qualified reviewer has yet attested these files. Before worship playback, a qualified Arabic listener must compare the actual audio against each complete card, including vowels, pauses, and extra words. Retain the identity and qualification of the reviewer, the script, file fingerprint and dated decision. For any excerpt, review the final cut and fingerprint it separately.

From a GitHub checkout, run `node docs/phase-one/recordings/restore-review-audio.mjs` before opening the listening page, running the recording audit, or building the private testing site. It restores the six original files from versioned publisher URLs and verifies every byte against the inventory. The private recovery ZIP already includes these files. Downloading a recording does not grant it religious approval.
